# Microduck 研发资料 — 实验室介绍

## 关于我们

我们是**天津建强智能科技有限公司**和**天津滨海职业学院**合作成立的 AI 和机器人实验室，从事以下方向：

- AI 模型的训练和部署
- 教培类机器人制作
- 机械臂的复刻
- 数字人的制作

## 创始人

我是天津建强智能科技有限公司的创始人**包建强**，拥有 20 年+ 的软件开发经验：

- 先后在**微软**、**惠普**等公司从事一线开发工作
- 先后在**艺龙**、**途牛**、**去哪儿网**担任高级技术总监

## 学生培养成果

在和天津滨海职业学院合作的一年多时间中，我培养了几个优秀的具备软硬件编程能力的学生，如**张波**、**韩迪岩**、**孙正旺**。他们能够：

- 从焊板子开始独立复刻机械臂、机器狗、蜘蛛、轮足机器人
- 独立训练和部署 AI 模型
- 编写 Agent

## 当前工作重点

实验室最近也在复刻这只鸭子，但是实验室做硬件的 2 个学生去准备专升本考试了，只剩下做 AI 编程的学生了。所以我们剩下这几个人就把精力花在 Microduck 的两个开源项目的研究上，包括：

- 机器人的底层代码
- 强化学习的训练

## 关于这份资料

我们在阅读代码的时候发现，里面掺杂大量的英文和法文注释和文档，每次都要用豆包进行翻译。为了方便所有 Microduck 研发人员快速上手，我们把 AI 生成的这部分资料全都分享出来。

本项目是基于 MicroDuck 的所有文档的翻译，以及所有代码和配置文件的解读，由这个学院的另外两个学生**马佳欢**和**李文军**完成。

## 下一步计划

1. **增加 Rust 这门语言的基础知识**。
2. 鉴于项目中保护 ONNX 模型，以及很多硬件研发人员连 3060 和 4090 的区别都搞不清，**增加一点深度学习和强化学习的基础知识，包括模型的训练**。
3. **复刻这只鸭子，并增加鸭子的组装流程**。
4. 在这些文档的基础上，**增加我们在鸭子的复刻中自己对代码的理解**，包括这个项目的整体设计、模块之间的交互、如何增加新的模块。未来可能会形成一本书。
